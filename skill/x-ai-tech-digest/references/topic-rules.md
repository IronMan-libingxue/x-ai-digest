# Topic Rules

Use this file only when the default scorer needs adjustment.

## Positive themes

- AI: `ai`, `llm`, `model`, `agent`, `gpt`, `openai`, `anthropic`, `claude`, `gemini`, `deepseek`, `inference`, `fine-tuning`, `rag`, `multimodal`, `embedding`, `vector`, `transformer`
- Chips and systems: `gpu`, `cpu`, `npu`, `cuda`, `tensor`, `chip`, `semiconductor`, `datacenter`, `server`, `cluster`, `rack`, `bandwidth`, `memory`, `hbm`
- Software engineering: `python`, `javascript`, `typescript`, `rust`, `go`, `compiler`, `runtime`, `framework`, `sdk`, `api`, `docker`, `kubernetes`, `linux`, `macos`, `windows`, `webgpu`
- Business and launches: `release`, `launch`, `benchmark`, `funding`, `acquisition`, `pricing`, `open source`, `paper`, `dataset`, `security`, `outage`

## Negative themes

- celebrity gossip
- sports
- pure politics without a direct tech policy angle
- generic memes
- trading noise with no technology content
- personal motivation content

## Ranking rules

- Prefer original reporting, screenshots of product launches, benchmarks, or code snippets.
- Prefer items that include a product name, model name, API, benchmark, release number, or hardware detail.
- Penalize vague hype and empty reposts with no text context.
- Penalize duplicates that discuss the same link with less detail.

## Digest shape

- Title: one line, Chinese
- Summary: 2-4 lines
- Items: 5-12
- Per item: source label, reason, direct link, 1-2 line summary
